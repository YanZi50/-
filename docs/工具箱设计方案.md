# 工具箱设计方案（第 5 步）

> 状态：已定稿（2026-09-15，用户确认全部决策点）
> 关联：README.md（使用文档）、CHANGELOG.md（变更记录）
> 本文件是工具箱功能的**设计档案与决策记录**：改代码前先读这里，避免凭记忆设计导致偏离。

## 0. 定位与不冲突原则

**工具箱 = 素材/文件加工厂；生成流程（左侧 1~4 步）= 成片组装厂。**

- 工具箱产物只流向两个地方：
  1. 工具箱自己的输出目录（`<输出目录>/toolbox/`）
  2. 经用户确认"存入素材库"后，才进入素材库供生成流程取用
- 生成流程只从素材库取料 → 两者唯一交集是素材库，天然解耦
- 工具箱**不读写**生成流程的 `state/configs/history`，参数独立存 `state/toolbox.json`
- 工具箱全部任务后台运行 + 进度 + 可取消，不阻塞页面

## 1. 页面结构（左侧第 5 步"工具箱"）

```
工具箱
├─ ① 语音识别与索引   （核心底座）
├─ ② 文本匹配拼接     （依赖①的索引）
├─ ③ 字幕包装         （样式模板 → 烧录）
├─ ④ 剪气口           （素材预处理）
└─ ⑤ 媒体工具         （转码/压缩/抽帧/音频/裁剪拼接）
```

## 2. 决策记录（已确认，勿改）

| 决策点 | 结论 | 理由 |
|---|---|---|
| 匹配模式 | **精确优先 + 语义兜底**（两级） | 素材库可能有原句直接命中；语义兜底提高召回 |
| 片段粒度 | **按句切子片段**（口播视频多句可复用） | 口播素材一条视频常含多句可用，整条匹配浪费 |
| 片段复用上限 | **同一片段（视频+起止时间）最多复用 2 次** | 防画面重复；超限置灰并提示 |
| 识别模型 | **默认 small（快）+ 可"精确模式重建"（large-v3）**，两套索引共存 | 快速可用优先；质量不满再升级，不强制所有人下载 1.5GB 模型 |
| 成片规格 | **跟随素材原始分辨率（默认）/ 1080×1920 / 1920×1080 / 自定义** | 用户可选项；"跟随原始"时片段分辨率不一致→统一为第一个片段的分辨率并提示 |
| 字幕烧录 | 文本匹配成片**自动烧录文案字幕**（样式默认极简，可换③模板），**同时保留无字幕副本** | 一步到位但用户随时能拿干净版 |
| 语义匹配实现 | **onnx 版 bge-small-zh-v1.5 + onnxruntime**，**不引 torch** | 便携包体积硬约束（引 torch → 2GB+），CPU 匹配毫秒级够用 |
| 剪气口 VAD | **silero-vad（onnx，约 2MB）**，独立于 ASR | 启动即用、极快，不依赖识别模型 |
| 语音识别引擎 | **faster-whisper（CTranslate2）** | 比原版 openai-whisper 快数倍、内存低 |

## 3. ① 语音识别与索引（底座）

- 识别对象：用户**显式选择的素材池/文件夹**（可多选），不盲目全库扫
- 模型：small（默认，约 460MB）/ large-v3（精确模式，约 1.5GB int8），可下载/指定本地路径
- 后台异步：进度 x/y、可暂停、可继续、可取消
- **断点续建**：已识别视频写入 `index/` 缓存，中断重启自动跳过已识别项，只增量识别新增
- 顺带产出：识别同时跑 VAD，记录**每句字幕时间轴 + 静音段位置**（气口），供②③④复用，不重复计算
- 存储：`index/` 每视频一个字幕 JSON（文本 + 句时间轴 + 静音段）+ embedding 向量缓存；几千视频约几十~几百 MB
- 粗筛（未来项）：索引前可做素材相似粗筛，省索引时间（第一版不做）

## 4. ② 文本匹配拼接

流程：输入文案 → 拆句 → 清洗（去语气词/标点归一）→ 两级匹配 → 片段选择去重 → 拼接 → 字幕烧录 → 产出

- 匹配：
  - 精确优先：字幕文本包含该句 → 命中
  - 语义兜底：bge-small-zh 相似度，阈值 60% 以下标注"匹配度低"
  - **短句优先**：拆句后先试短句（命中率高），整句未命中再降级
- 片段选择：片段唯一键 = `来源视频路径 + 起始时间 + 结束时间`；复用计数可靠不误判；超 2 次自动换候选
- 气口联动：切子片段自动避开 VAD 静音段（索引时已算好，零额外成本）
- 拼接：复用现有 ffmpeg 拼接 + 转场（转场跟随参数配置，默认不使用）
- 产物：输出到 `toolbox/文本匹配/`，可选"存入素材库"；**同时保留无字幕副本**
- 匹配度报告：每条句子标注来源视频、时间段、匹配度（高/中/低），片段可点击播放

## 5. ③ 字幕包装

- 输入：SRT/ASS（来自①识别 / ②文案 / 用户手选文件）
- 样式模板：极简白字 / 描边黄字 / 气泡款 / 弹幕风（ASS 模板：字体/字号/颜色/描边/阴影/位置/入场动画）
- 输出：导出 SRT/ASS；或烧录到视频
- **与生成页联动**：生成页"自动字幕"选项升级为样式选择（无/极简/描边/气泡/弹幕），复用本模块模板

## 6. ④ 剪气口

- 输入：任意视频（或素材库）
- 参数：灵敏度、最短剪切长度（默认 0.6s）、保留句间留白（默认 0.3s）
- 实现：silero-vad 检测静音段 → ffmpeg 按时间轴剪切拼接
- 输出：剪好的片段 → 可选"存入素材库"
- 注意：仅口播/人声素材有效，界面标注"音乐/纯画面素材请勿使用"

## 7. ⑤ 媒体工具（FFmpeg）

- 转码（格式/分辨率/码率/帧率）、压缩（质量 CRF / 目标大小）、抽帧（按秒/按数量）、音频（提取/转码）、裁剪拼接
- 输入：文件夹（批处理其中匹配文件）或单文件；输出到 `toolbox/<工具名>/`
- 全部参数化拼接 ffmpeg 命令：**素材路径含中文/空格必须转义，防命令注入**（硬性要求）

## 8. 可维护性设计（硬规则）

**模块划分**（新增 `toolbox/` 包，与现有代码零耦合）：

```
toolbox/
├─ engine.py    # 媒体工具：ffmpeg 命令参数化拼接（转义/防注入/超时/失败返回 stderr）
├─ asr_index.py # 索引：识别/断点续建/增量/两套模型索引共存
├─ matcher.py   # 文本匹配：拆句/清洗/精确+语义/片段选择与复用计数
├─ subtitle.py  # 字幕包装：ASS 模板生成/烧录
├─ vad_cut.py   # 剪气口：silero-vad 静音段裁剪
├─ store.py     # 索引存储：原子写、损坏单条自愈（不整库崩）
└─ models.py    # 模型下载/路径/校验（small/large-v3/bge/silero-vad）
```

**防 bug 硬规则**：
1. 语义匹配**不引 torch**（onnxruntime 即可，便携包体积约束）
2. 所有 ffmpeg 调用统一走 `toolbox/engine.py` 封装（转义/超时/失败诊断），禁止散落裸调
3. 索引 JSON 原子写入（先写临时文件再改名）；损坏条目自动重建该视频，绝不因一条坏数据崩整个索引
4. 工具箱全部任务后台跑 + 进度 + 可取消；配置存 `state/toolbox.json`，不碰生成流程
5. 每模块配单测（复用 smoke_test 模式）；拼接/匹配/剪气口用生成测试素材跑，改一处不回归其他

## 9. 性能设计（几百~几千个视频）

| 场景 | 设计 |
|---|---|
| 首次全量索引（small） | 约 2~4s/30s 视频 → 2000 个约 1.5~3 小时（后台 + 断点续建，可关程序下次接着来） |
| 首次全量索引（large-v3） | 约 3 倍时长（5~9 小时） |
| 增量索引 | 只识别新增视频，秒级~分钟级 |
| 语义匹配 | 几千条向量 numpy 点积，毫秒级 |
| 存储 | `index/` 缓存可一键清理（重建不丢功能） |

## 10. 开源平替调研（记录，暂不实施）

| 模块 | 平替 | 结论 |
|---|---|---|
| 中文口播识别 | FunASR（阿里 Paraformer，中文强于 whisper，自带 VAD+标点） | 依赖 torch，与体积约束冲突；**若中文效果不满意再评估 onnx 版** |
| 剪气口 VAD | silero-vad（已采纳） | 极轻，独立于 ASR |
| 语义匹配 | text2vec / m3e | 维持 bge（社区最稳、onnx 生态好） |
| 媒体工具 UI | LosslessCut 交互式裁剪 | 交互式裁剪工作量超预算，未来项 |
| GPU 加速 | faster-whisper CUDA 版 | 便携包默认不带，需要的人另装（文档记录） |

## 11. 实施顺序（每步独立交付、可回滚）

```
⑤ 媒体工具（无依赖，最快见效）
→ ① 语音识别与索引（底座，断点/增量/进度）
→ ③ 字幕包装（复用①产物，顺带升级生成页字幕选项）
→ ④ 剪气口（复用 VAD）
→ ② 文本匹配拼接（依赖①③，工作量最大）
```
