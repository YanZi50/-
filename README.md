# 信息流素材一键拼接

一个本地网页版小程序：选择开头文件夹和结尾文件夹，一键批量生成不同组合的 MP4 视频。

## 核心功能

- 上传或手动填写开头文件夹、结尾文件夹；
- 可选固定开头或固定结尾；
- 自动组合生成 1–200 条视频；
- 输出 1080×1920 或 1920×1080 MP4；
- 目标时长可选：不限制、15s、25s、30s；
- 可选水印、转场、BGM；
- 支持暂停和取消；
- 本地处理，素材不上传服务器。

## 运行

1. 双击 `安装依赖.bat`；
2. 双击 `启动.bat`；
3. 浏览器打开 `http://127.0.0.1:8765`。

## 使用

1. 上传或填写开头文件夹、结尾文件夹；
2. 点击“扫描素材”；
3. 设置出片数量、分辨率、时长；
4. 按需勾选水印、转场、BGM；
5. 点击“开始生成”；
6. 完成后在页面底部下载输出文件。

## 主要文件

- `web_app.py`：本地网页服务；
- `web/index.html`：操作页面；
- `video_engine.py`：视频处理核心；
- `需求文档.md`：需求说明。

## 说明

- 视频处理使用 FFmpeg，全部在本机完成；
- 通过页面上传的素材会保存到本地 `uploads` 目录；
- 任务取消后，已经生成的视频会保留。
